# Biopharma Python Journey

Computational chemistry, analytical data processing, and biopharmaceutical formulation scripts written in Python.

### Focus Areas
- **Analytical Chemistry Automation:** Molarity, standard dilutions, and chromatographic data workflows.
- **Physicochemical Drug Profiling:** Evaluating solubility, lipophilicity (LogP), and Lipinski's Rule of 5 for small molecules vs. biologics.
- **Therapeutic Peptides & Materials:** Sequence stability profiling and polymer-drug carrier modeling.
